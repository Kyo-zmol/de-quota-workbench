## 六大模块（左图标轨）
1. **查定额**：三栏（章树/结果/详情）；全字段搜索含材料名反查；详情三页签＝组成｜相关规则｜我的笔记
2. **组价工作单**：清单行→选定额→数量；换算系数/材料换价随行；右侧实时汇总＝分部分项（人材机管利税）＋总价措施费（按专业费率）＋增值税→单位工程造价；多工作单保存/载入；导出 Markdown
3. **换算计算器**：人工/材料/机械系数滑杆＋材料换价表；原基价 vs 换算后对照＋差额；费用按原隐含费率重计、增值税按原税率重计；可应用到工作单行或存为笔记
4. **规则与说明**：17,577 条说明文本检索（系数/换算/计算规则），带册/章/节/页码出处
5. **我的笔记**：Obsidian `03-Resources/定额笔记/<编号>.md` 列表与回跳
6. **设置**：数据状态、热加载、重看引导

## 组价口径（透明可核）
- 综合单价＝换算后全费用（含定额内增值税）；合价＝综合单价×(清单量÷定额单位基数)
- 措施费＝(人工费+机械费)合计×专业费率（安全文明+其他总价措施）
- 单位工程造价＝(分部分项+措施)×(1+增值税率)，一般计税 9% / 简易 3%
- 换算重计：费用=原隐含费率×(新人工+新机械)；增值税=原税率×新税前合计

## 开源发布（GitHub）合规方案 · 2026-09-09
**结论：可以上 GitHub，但代码与数据必须分离。**
- 仓库只含：app/（服务+前端）、scripts/（解析器）、DESIGN.md、README、LICENSE(MIT)、Dockerfile
- **不入库**（.gitignore 已列）：data/raw 官方PDF、data/processed 解析结果、data/projects 工作单、notes 笔记、artifacts、desktop（Electron 110MB）
- 理由：①官方定额发布件虽为政府公开文件，但批量解析结果随仓分发存在衍生作品争议，且体积大；②工作单/价本/笔记含个人商业信息
- 他人复现路径：README 数据获取节（住建厅官网链接）→ scripts/parse_all.js 自行解析 → 本地数据
- 部署选项：
  1. **VPS/云主机**（推荐，全功能）：Dockerfile 一键（node:20-alpine，挂载数据卷）
  2. **Render/Railway** 免费档：同 Dockerfile
  3. **GitHub Pages 静态演示**：需改造为纯前端+浏览器内加载用户自传数据（BYO-data），暂不做，避免任何数据随仓分发
- 推送步骤（需你的 GitHub 凭据）：
  git remote add origin https://github.com/<你的用户名>/de-quota-workbench.git
  git push -u origin main
